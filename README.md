# Scrimba Intro to Design Fundamentals

Challenge solutions from Scrimba's Intro to Design Fundamentals course. Each challenge starts from an unpolished HTML/CSS layout and fixes one design problem: whitespace and alignment, contrast, color, or visual hierarchy.

## Contents

| Folder | What it covers |
| --- | --- |
| `Challenge1/` | Whitespace and alignment: three blog cards (image block, date, title, description) in a three-column CSS Grid, with padding and left-aligned dates. |
| `Challenge2/` | Contrast: dark-theme list of cards with a round image placeholder, adjusted text and background colors so the content reads clearly. |
| `Challenge3/` | Color: "Contact us Today" form (inputs, textarea, submit button) on a dark background, plus a row of five color swatches. |
| `Challenge4/` | Visual hierarchy: "Pay your debts" call-to-action card with an SVG arrow icon, body text and a "Find out how" button. |
| `FinalChallenge/` | Dashboard layout: sidebar plus a "Sales Report" panel listing earnings, refunds, chargebacks and net income, using CSS Grid. |

## How to run

Open the `.html` file in each folder in a browser. Styles use the Nunito font from Google Fonts, so a connection is needed for the intended typography.

Note: `Challenge4/Challenge4.html` and `FinalChallenge/finalchallenge.html` link to `index.css`, but their stylesheets are named `Challenge4.css` and `finalchallenge.css`. Those two pages render unstyled unless the `<link>` is pointed at the right file.

## Tech

- HTML5
- CSS3 (Grid, Google Fonts)
- Inline SVG
